Aprenda a criar sites utilizando HTML, CSS, JavaScript, Bootstrap e Visual Studio Code.

Conheça a matéria

O que é Desenvolvimento Web?

Desenvolvimento Web é a área responsável pela criação de sites e páginas para a internet. Na matéria, aprendemos a estruturar páginas com HTML, estilizar com CSS, adicionar interatividade com JavaScript e utilizar ferramentas como Bootstrap e Visual Studio Code.

Visual Studio Code

O VS Code é o editor usado para criar e organizar os arquivos dos projetos. Nele podemos trabalhar com HTML, CSS e JavaScript em um mesmo ambiente.

HTML, CSS e JavaScript

HTML cria a estrutura, CSS define o visual e JavaScript adiciona comportamentos e interações. Juntas, essas tecnologias formam uma base importante do desenvolvimento web.

Sites responsivos

Aprendemos também a fazer páginas que se adaptam a diferentes tamanhos de tela, funcionando bem em computadores, tablets e celulares.

Aprender fazendo

A matéria combina teoria e prática. Criamos páginas, organizamos arquivos no VS Code, testamos no navegador e corrigimos o código até o projeto funcionar.
